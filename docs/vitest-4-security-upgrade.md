# Vitest 4 security compatibility upgrade

This increment evaluates upgrading the repository test runner from Vitest 1.x to the current stable Vitest 4 line in order to remove development-only security advisories without changing analytical production behavior.

The target selected after checking the current official Vitest documentation and npm package metadata is Vitest 4.1.10.

Vitest 4 requires Node.js 20 or newer and Vite 6 or newer. The repository CI already runs Node 20, so the Node runtime does not need to change for this upgrade.

The current `vitest.config.ts` only defines the test include pattern. The repository does not configure coverage, browser mode, custom pools, deprecated dependency inlining options, or custom environments. Representative analytical tests use the standard `describe` / `it` / `expect` surface. The upgrade is therefore expected to require dependency migration rather than production-code changes.

The upgraded lockfile must be generated by npm tooling. The temporary upgrade CI records the full and production-only audit results and commits the npm-generated lockfile to the upgrade branch. Before merge, CI is restored to locked `npm ci` installation and the complete typecheck, test, build, and packed-consumer boundaries are rerun.

No registry publication, package version release, `private` flag change, analytical formula change, or public API change is part of this increment.
