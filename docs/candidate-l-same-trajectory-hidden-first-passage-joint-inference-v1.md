# Candidate L — Same-Trajectory Hidden Observation + First-Passage Joint Inference v1

Authority: `ORF-ABC-SAME-TRAJECTORY-HIDDEN-FIRST-PASSAGE-JOINT-INFERENCE-FOUNDATION-v1`

Operating mode: `QUALIFIED_SCOPE_HOLD`

## Purpose

Candidate L adds a finite, domain-independent Seikatan capability for evidence generated by the same stochastic trajectory. A hidden-observation sequence and a first-passage condition are evaluated as one joint likelihood. The implementation does not multiply Candidate F and Candidate G marginal likelihoods and does not assume conditional independence between same-trajectory evidence.

For candidate `c_i`, the ranking likelihood is:

- exact first hit: `P_i(Y_0..Y_T, tau=t)` with `0 <= t <= T`
- right-censored: `P_i(Y_0..Y_T, tau>T)`

where `tau` is first entry into the candidate target set.

## Candidate contract

Each caller-supplied candidate provides:

- unique non-empty `candidateId`
- fixed finite `DefinitionModel`
- explicit finite initial distribution totaling one within probability tolerance
- finite non-empty observation alphabet
- known observation kernel with each state row totaling one within tolerance
- finite non-empty target-state set with the same caller-declared external event meaning across candidates
- optional finite JSON-scalar candidate value for downstream existing Kiyotan composition

No candidate is silently normalized, dropped, generated, optimized or learned.

## Observation timing

Candidate C timing is retained exactly:

1. draw `X_0` from the supplied initial distribution
2. emit `Y_0` from `X_0`
3. transition `X_s -> X_{s+1}`
4. emit `Y_{s+1}` from `X_{s+1}`

The shared observation sequence is finite and non-empty: `Y_0..Y_T`.

## First-passage semantics

Candidate B semantics are retained exactly:

`tau = inf{s >= 0 : X_s is in targetStates}`

Step 0 therefore counts as a first hit.

The source model is not mutated. Target states need not be terminal. Existing implicit self-retention for terminal states remains in force, and parallel transition probabilities aggregate.

## Supported passage conditions

### `exact_hit_at_step`

For step `t`, where `0 <= t <= T`, the joint event requires:

- every state before `t` is outside the target set
- state at `t` is inside the target set
- after `t`, the original model continues without additional target restrictions
- all observations through `T` remain part of the likelihood

Thus the implementation still conditions on observations occurring after an earlier first hit.

### `not_hit_by_observation_horizon`

The joint event is `tau>T`. Every hidden state from step 0 through `T` must remain outside the target set while all observations are simultaneously conditioned.

No interval, left, noisy or competing-risk passage observation is included in v1.

## Stable joint likelihood

Production uses a scaled constrained forward recurrence.

At each step it applies the emission probability and the first-passage state mask simultaneously, sums the admissible mass into a scale factor, normalizes the constrained state distribution, and accumulates the logarithm of the scale factor.

A mathematically possible candidate retains finite `jointLogLikelihood` even when `Math.exp(jointLogLikelihood)` underflows to zero in Float64. `jointProbabilityUnderflowed` reports that representational condition. Underflow is not mathematical impossibility and cannot affect ranking.

Mathematical probability zero returns `possible:false`, `jointLogLikelihood:null`, no fabricated winner, and the first step at which the constrained evidence became impossible.

## Maximum-likelihood classification

Possible candidates are ranked only by finite joint log likelihood.

Let `ell*` be the largest finite joint log likelihood. Every possible candidate satisfying

`abs(ell_i - ell*) <= comparisonTolerance`

is retained in the selected set.

Classification is one of:

- `unique_maximum_likelihood`
- `tied_maximum_likelihood`
- `all_candidates_impossible`

Candidate input order and candidate ID cannot break an analytical tie.

A unique maximum-likelihood candidate is unique only relative to the supplied finite candidate family, the supplied same-trajectory evidence, and the disclosed tolerance. It is not a global structural-identifiability or model-truth claim.

## Candidate-value bridge

Optional caller-supplied JSON-scalar candidate values are preserved in per-candidate and selected-candidate output. This is an upstream Seikatan-to-existing-Kiyotan bridge only; Candidate L does not modify Kiyotan evaluation contracts.

## Failure semantics

Failures are explicit for invalid options, empty or duplicate candidate families, invalid candidate scalar values, empty or oversized observation sequences, invalid exact-hit steps, unsupported passage conditions, candidate-specific model/initial-distribution/kernel/target validation failures, non-finite analytical arithmetic, and forged non-finite serialization values.

A mathematically impossible joint observation is an analytical result, not a request-validation failure.

## Independent qualification

Candidate L qualification must not use Candidate L production recurrence as its expected-value oracle.

Primary oracle:

- complete finite hidden-path enumeration
- independent multiplication of initial, transition and emission probabilities
- direct first-passage classification of each path
- summation only over paths satisfying both the observation sequence and passage event

Secondary oracle:

- independently constructed dense transition matrix
- independent emission masks
- non-target masks before an exact hit
- target mask at the exact hit
- no passage mask after the exact hit
- non-target masks at every observed step for right censoring

Required reduction/dependence checks include:

- uninformative emissions reduce candidate ranking to Candidate G first-passage inference up to a common emission factor
- a passage condition that is certain reduces to Candidate F hidden-observation inference
- a genuinely dependent same-trajectory fixture differs from naive `P(Y)*P(passage)` multiplication
- direct joint-probability underflow does not alter finite-joint-log-likelihood ranking
- candidate order and equivalent split-parallel transitions do not alter results
- exact ties and candidate values are preserved
- all-candidates-impossible remains an analytical success

## Explicit non-claims

Candidate L does not qualify:

- Bayesian candidate priors or posterior probabilities
- posterior normalization
- arbitrary evidence weights or likelihood exponents
- automatic independence testing
- unknown observation-kernel learning
- continuous parameter fitting or automatic candidate-family generation
- smoothing or Viterbi decoding
- observation/experiment design
- interval/noisy censoring or competing risks
- infinite-horizon absorption inference
- stationary or limiting distributions
- global structural identifiability
- cyclic/general MDP optimization
- causal or counterfactual inference
- a new Wave, Level, principal application or Showcase
- EXTREP state changes
- release of `QUALIFIED_SCOPE_HOLD`

## Candidate K boundary

Candidate K remains the authority for bundles of caller-declared conditionally independent evidence episodes. Candidate L is different: it directly models hidden-observation and first-passage evidence from the same trajectory. Same-trajectory evidence must not be routed through Candidate K merely to multiply dependent marginal likelihoods.

Historical project-wide qualification evidence and Candidate A/B/C/D/F/G/K targeted subjects remain unchanged unless separately authorized.
