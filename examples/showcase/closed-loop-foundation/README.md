# ORF Closed-Loop Foundation Showcase

This executable example presents a domain-neutral finite probabilistic process in a closed Seikatan → Kiyotan loop using only already-qualified Public APIs from this repository.

## What the example demonstrates

The primary lane starts from realized observations and fixed calibrated evidence. Candidate AJ performs bounded convergence-controlled iterative re-estimation. Its returned `finalTheta` is then passed directly into existing Kiyotan computations:

`Candidate AJ → Candidate A → Candidate B → Candidate J → Candidate AA → Candidate AB`

The fixture deliberately limits AJ to two accepted iterations. The expected result is therefore an honest bounded non-convergence result:

- `converged: false`
- `stopReason: MAX_ITERATIONS_REACHED`
- `acceptedIterations: 2`
- both accepted likelihood updates remain visible
- the returned non-converged `finalTheta` is still the exact downstream input
- no known/truth parameter is substituted after re-estimation

The Kiyotan side reports finite-horizon state distribution, finite first passage, finite-chain stationary/Cesàro behavior, an additive trajectory-functional distribution, and the same additive outcome under separate declared calibrated local evidence.

The secondary lane demonstrates ambiguity preservation:

`finite candidate inference → Candidate D-compatible finite-family classification → unresolved set → per-candidate Candidate A values → Candidate M maximin decision`

Two candidates remain unresolved under the declared observation design. They are not averaged or replaced by an invented truth. Their predictions differ, yet the supplied pure-action maximin problem still has the unique robust action `safe`.

## Reproduce

From the repository root, with a supported Node.js version:

```sh
npm ci --no-audit --no-fund
npm run build
node examples/showcase/closed-loop-foundation/runner.mjs --verify
```

`--verify` compares the complete machine-readable result against `expected-result.json`. Numeric comparison uses a disclosed `1e-10` relative/absolute scale tolerance. The expected values were fixed from independent finite calculations rather than generated by copying the runner output.

Files:

- `fixture.json` — deterministic input fixture
- `runner.mjs` — Public-source executable orchestration
- `expected-result.json` — independently fixed machine-readable expected result
- `../../../docs/showcase/closed-loop-foundation.md` — technical provenance and claim boundary

For the package-name consumer path, see `../../../docs/current-generation-consumer-quickstart.md`.

## Inputs shown in the output

The runner prints JSON containing:

- realized observations `[0, 1, 1, 0]`
- AJ initial calibrated evidence and every monitor-coupled transition evidence layer
- the separately declared downstream Candidate AB calibrated evidence
- AJ likelihood/iteration trace
- convergence status and exact stop reason
- AJ `finalTheta`
- A/B/J/AA/AB downstream results
- the unresolved secondary candidate set
- per-candidate Kiyotan predictions/action values
- Candidate M robust decision
- explicit ambiguity and claim-boundary flags
